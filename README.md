## Getting the files

- **Everything at once:** the green **Code** button at the top of this page →
  **Download ZIP**.
- **Arduino sketches** (`arduino/NN_name/NN_name.ino`): open in the Arduino IDE. Keep each
  `.ino` inside its folder with the same name, or the IDE complains.
- **Processing sketches** (`processing/name/name.pde`): copy the whole folder, then open the
  `.pde` in Processing 4.
- **3D parts** (`3d/*.stl`): click one here to turn it around in 3D; print the `.stl`.
  `.step` is for Fusion or Onshape, `.scad` for OpenSCAD.

Each guide has its own building steps, troubleshooting, and the credits for the tutorials it
builds on.
