# Original code

The radar is based on the **Arduino Radar Project** by Dejan Nedelkovski,
HowToMechatronics.com: <https://howtomechatronics.com/projects/arduino-radar-project/>

Copied from that article on 2026-11-13, unchanged apart from a short header at the top
(source, author, date):

- `howtomechatronics-radar.ino`: the Arduino code. Ours: `../arduino/03_radar/`.
- `howtomechatronics-radar-display.pde`: the radar screen in Processing, the article's
  "updated version". Ours: `../processing/radar_display/`.

They're here for comparing, not for running, so don't change them. The guide
(`../README.md`) lists every difference under "What we changed compared to the original".
